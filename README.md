
# Разработка веб-сайта для ветеринарной клиники

**Статус:** В разработке  
**Учебная группа:** К-ИСП-231  
**Учебный год:** 2026–2027
## 1. Описание проекта

Разработка современного веб-сайта для ветеринарной клиники направлена на упрощение взаимодействия владельцев животных с ветеринарными специалистами. Главная цель проекта — создание удобной цифровой платформы, избавляющей от необходимости звонить по телефону. На сайте будет представлена информация об услугах, их стоимости и профилях врачей, а также реализована функция онлайн-записи на прием. Итоговый результат — функциональный и понятный ресурс, который экономит время как клиентам, так и сотрудникам клиники.
